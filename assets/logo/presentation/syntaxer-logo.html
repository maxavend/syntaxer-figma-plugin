What we heard

The brief

A Figma plugin that turns variable paths into code syntax for Web, Android and iOS. The mark should feel precise and friendly, read at 16 px in the plugin menu, and step away from the generic </> code icon.

precisesystematicfriendlynative to Figma

Distinct from other code plugins, recognisable at 16 px, works in one colour, and carries a Liquid Glass expression for the icon.

Final design

Split token

A Figma variable hexagon split by a slash into a < and a >: the path becomes code.

  • The hexagon is the variable, the slash is the path separator, the halves are code brackets
  • Pink is the design side, teal the code side; the gap between them is what Syntaxer does
  • Built on 60° geometry; the wordmark's x and y reuse the same angle and slash cut
  • Flat masters for one colour and small sizes, Liquid Glass layers for the icon
